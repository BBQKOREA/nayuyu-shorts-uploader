Privacy Policy — Nayuyu Shorts Uploader

Effective date: 26 September 2026

1. Summary

Nayuyu Shorts Uploader ("the Application") is a private tool used by a single operator to publish their own videos to their own social media accounts. It has no users other than that operator. It collects no data from anyone else, and it sends no data to anyone except the social media platforms the operator is publishing to.

2. What data the Application handles

DataWhyWhere it is kept
Video files and their captionsTo publish themThe operator's own computer

That is the complete list. The Application requests these TikTok permissions and no others:

  • user.info.basic — to confirm which account is connected
  • video.publish — to publish the operator's videos
  • video.list — to read the performance of the operator's own videos

3. Data belonging to other people

None is collected. The Application does not read the operator's followers, friends, contacts, direct messages, or any other user's content. It does not access the phone address book or any contact list. It performs no analytics on other people.

4. Where data is stored, and for how long

All data stays on the operator's own computer. Nothing is uploaded to any server belonging to the Application, because no such server exists.

  • Access tokens are kept until they expire or the operator disconnects the account.
  • Video files, captions and statistics are kept until the operator deletes them.

5. Sharing and selling

Data is never sold, rented, traded, or shared. The only outbound transmissions the Application makes are direct API calls to TikTok and Instagram, carrying the operator's own video, the operator's own caption, and the operator's own access token.

No advertising network, analytics provider, or other third party receives anything.

6. Revoking access and deleting data

The operator can revoke the Application's access at any time:

  • In TikTok: Settings and privacy → Security and permissions → Manage app permissions
  • In the Application: disconnect the account, which deletes the stored token file

Deleting the Application's folder removes every piece of data it holds.

7. Children

The Application is not directed at children and is not usable by anyone other than its operator.

8. Security

Access tokens are stored in local files on the operator's own computer, which is protected by the operating system's own account security. Credentials are never transmitted anywhere except to the issuing platform over HTTPS.

9. Changes

This policy may be updated. The effective date above indicates the most recent revision.
